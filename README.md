# SWYNEX-Data-Preparation

## Project Overview

This project was completed as part of my SWYNEX internship Task 1.

The objective was to prepare a business dataset for future Power BI analysis.

## Dataset

The dataset contains 1,200 business sales records covering January 2024 to December 2025.

The dataset includes information about:

- Orders
- Sales
- Profit
- Products
- Categories
- Regions
- Cities
- Customer Segments
- Salespeople
- Quantity
- Discounts

## Data Preparation

The dataset was cleaned and prepared using Excel/Power Query concepts.

The main transformations included:

1. Removing duplicate records
2. Trimming unnecessary spaces
3. Standardizing text values
4. Handling missing values
5. Correcting data types
6. Creating Year and Month fields
7. Creating Quarter fields
8. Creating Profit Margin
9. Organizing the final dataset for Power BI

## Files

- `SWYNEX_Data_Preparation_Business_Dataset.xlsx` – Complete workbook containing raw data, cleaned data and transformation documentation.
- `SWYNEX_Cleaned_Business_Sales_Data.csv` – Cleaned dataset.

## Outcome

The final dataset is structured and ready to be imported into Power BI for further analysis and dashboard development.
